# Ad photographs

Freely-licensed stock, used in the pop-up advertisements. Filenames here are the slot
each one fills; the original upload is named alongside it.

Each was resized to fit 240px on its long edge and reduced to a 128-colour palette
with per-index alpha (`tRNS`), which took the set from 39 MB to 96 KB. Nothing in an
ad renders wider than about 120 CSS pixels, so nothing visible was lost.
